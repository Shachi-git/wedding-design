Emma & Daniel — Wedding Website

A modern, elegant wedding website designed to give guests a beautiful and memorable digital experience. The website brings the couple's story, wedding details, schedule, gallery, RSVP, and frequently asked questions together in one responsive experience.

Wedding information can be managed from:

data/wedding.ts

This includes details such as:

Couple names

Wedding date

Venue

City

Schedule

Gallery images

FAQ content

Wedding information

The main hero image and shared components can also be customized to match the couple's preferred style.

🚀 Getting Started

Install the dependencies:

npm install

Run the development server:

npm run dev

Then open:

http://localhost:3000

💍 Purpose

This project is designed as a custom wedding website experience, rather than a traditional digital invitation. It gives couples a dedicated online space where their story and wedding information can be presented beautifully to their guests.
